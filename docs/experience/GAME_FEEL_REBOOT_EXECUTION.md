Direct choice IDs still pass through canonical P6; Native and production Chromium verification on the PR exact head are REQUIRED before merging.
- **P4b/P4c NOT YET IMPLEMENTED:** existing P1/P2 ambient conversations and Mahmoud's invitation remain autonomous, but actual P6 response windows still wait indefinitely. Next: P1 world-minute deadlines, deterministic authored silence/ignore/leave outcomes and saved/replayed relationship/opportunity consequences. No local countdown/game-state timer; do not claim a live social system from P4a UI alone.
- **Movement granularity:** P0 solved the repeated easing discontinuity in the renderer but did not change the canonical P2 17-unit step or camera/zoom's subjective comfort. Real device/human playtest is mandatory before calling smoothness done.
- **Visual approval:** The isometric schematic remains provisional; human-signoff-gated V001 art is unchanged.
